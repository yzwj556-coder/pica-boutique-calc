# pica-boutique-calc

洛克王国 · 皮卡商店 时装（印象）许愿星计算器（非官方粉丝工具 · 与腾讯/魔方工作室无关 · 素材来源于游戏内截图，仅供玩家交流参考）。

原项目：https://chercheurrr.github.io/pica-calculator/
本仓库为重构增强版：https://yzwj556-coder.github.io/pica-boutique-calc/

## 功能

- **时装（印象）卡池管理**：内置 59 套时装（18 套金装 + 41 套紫装），每套配本地图片。
- **两档价格体系**：
  - 金装：整套 **195** 许愿星，6 个配件（连衣 74 / 头饰 41 / 背饰 34 / 手饰 17 / 袜子 9 / 鞋子 20）。
  - 紫装：整套 **98** 许愿星，有两套价格体系：
    - 6 件：连衣 42 / 头饰 20 / 背饰 18 / 手饰 6 / 袜子 4 / 鞋子 8。
    - 7 件：上衣 21 / 裤子 21 / 头饰 20 / 背饰 18 / 手饰 6 / 袜子 4 / 鞋子 8。
- **整套勾选**：每张卡片上可直接勾选「整套」，= 勾选该套装全部配件（按正常模式扣/返许愿星）。
- **实时统计**：许愿星总数（购买全部套装所需）、毕业所需许愿星（= 当前缺口许愿星）、总时装数、总配件数、已拥有配件、未拥有配件、已毕业套装、已拥有许愿星价值，勾选/上传新套装后全部自动更新。
- **预算规划**：已有许愿星库存、今日获取量、还需许愿星（扣除库存）、预计毕业天数、提交历史；补录模式（不扣星录数据）。
- **收藏 / 筛选 / 排序 / 搜索 / 性别**：保留原网站功能（性别切换暂用同一套图片，可单独指定男/女图）。
- **图表**：纯 SVG 环形图（整体进度 / 收藏进度），无外部依赖，离线可用。
- **管理面板**：上传新套装图片文件、选择金装/紫装、紫装选 6 件或 7 件、修改各配件价格；上传后所有数值自动变化。
- **编辑模式**：点击页面任意文字可直接修改；一键切换套装 金装⇄紫装、紫装 6件⇄7件；批量编辑页面文字与价格体系。
- **数据持久化**：勾选状态、收藏、预算、自定义套装、文字/价格修改均保存在浏览器 localStorage / IndexedDB；支持导出/导入 JSON 备份。

## 目录结构

```
pica-boutique-calc/
├── index.html         页面结构
├── css/style.css      样式
├── js/
│   ├── data.js        所有数据：页面文字 TEXT、价格体系 PRICE_SCHEMES、内置套装 BUILTIN_SUIT_NAMES
│   ├── app.js         核心逻辑：状态、预算、统计、渲染、图表、导入导出
│   └── admin.js       管理面板：添加/编辑套装、图片上传、编辑模式
└── images/            59 张时装图片（images/<套装名>.png）
```

## 如何修改（给开发者）

- **改文字**：网页里开「编辑模式」直接点文字改，或改 `js/data.js` 的 `TEXT`。
- **改价格/配件名**：网页「编辑模式 → 编辑价格体系」，或改 `js/data.js` 的 `PRICE_SCHEMES`。
- **加套装（永久内置）**：把图片放进 `images/`，在 `js/data.js` 的 `BUILTIN_SUIT_NAMES` 对应数组里加一行名字；默认按紫装 6 件处理，需要单独价格的套装在 `BUILTIN_SUITS` 构建后追加 `{ name, type, partCount, prices, image }` 对象。
- **加套装（网页操作）**：点「➕ 添加套装」上传图片并填写信息，保存后立即生效（存在本浏览器）；如需永久保留，点「导出 data.js 代码片段」把 `EXTRA_SUITS` 粘贴进 `js/data.js` 末尾，并把图片文件放入 `images/`。
