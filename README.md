# pica-boutique-calc

洛克王国 · 皮卡商店 时装（印象）许愿星计算器（非官方粉丝工具 · 与腾讯/魔方工作室无关 · 素材来源于游戏内截图，仅供玩家交流参考）。

原项目：https://chercheurrr.github.io/pica-calculator/
本仓库为重构增强版：https://yzwj556-coder.github.io/pica-boutique-calc/

## 功能

- **时装（印象）卡池管理**：内置 58 套时装（18 套金装 + 40 套紫装），每套配男女装两张图片；按 **17 个主题**分组展示（每个主题 3~4 套时装，品质一致，一个主题 = 一批）。
- **入池机制**：新时装按主题顺序进入许愿星商店。统计拆分：**许愿星总数**（全部）、**毕业所需许愿星**（全部缺口，含未入池）、**当前缺口许愿星（已入池）**、**未入池许愿星总数**（未入池套装缺口，勾选未入池时装会随之减少）、**未入池时装数**。默认最后 4 个主题未入池，编辑模式可改；上传新主题时最旧未入池主题自动入池。
- **主题整体操作**：每个主题行有「勾选该主题全部时装」；非编辑模式只显示序号最小的未入池主题的入池时间；编辑模式可设置每个主题的「已入池 / 入池时间」。
- **多账号**：可新建/重命名/删除多个账号，每个账号拥有独立的许愿星库存、已拥有配件、收藏与性别设置，互不影响；时装、图片、主题、页面文字等配置所有账号共用。
- **两档价格体系**：
  - 金装：整套 **195** 许愿星，6 个配件（连衣 74 / 头饰 41 / 背饰 34 / 手饰 17 / 袜子 9 / 鞋子 20）。
  - 紫装：整套 **98** 许愿星，有两套价格体系：
    - 6 件：连衣 42 / 头饰 20 / 背饰 18 / 手饰 6 / 袜子 4 / 鞋子 8。
    - 7 件：上衣 21 / 裤子 21 / 头饰 20 / 背饰 18 / 手饰 6 / 袜子 4 / 鞋子 8。
- **整套/主题勾选**：每张卡片可勾选「整套」；每个主题行可勾选「该主题全部时装」（均按正常模式扣/返许愿星）。
- **实时统计**：许愿星总数、毕业所需许愿星、当前缺口（已入池）、未入池许愿星总数、未入池时装数、总时装数、总配件数、已拥有配件、未拥有配件、已毕业套装、已拥有许愿星价值，勾选/上传后全部自动更新。
- **预算规划**：已有许愿星库存、今日获取量、还需许愿星（扣除库存，按毕业所需）、预计毕业天数、提交历史；补录模式（不扣星录数据）。
- **收藏 / 筛选 / 搜索 / 性别**：保留原网站功能。图片按性别命名：`images/<套装名>女装.png` 与 `images/<套装名>男装.png`；切换性别显示对应图片，男装图缺失时自动回退显示女装图。
- **使用说明（可折叠）**：页面顶部有「查看未毕业套装已有的配件」教程（`images/教程-查看未毕业套装已有的配件.png`），点击展开/折叠。
- **图表**：纯 SVG 环形图（整体进度 / 收藏进度），无外部依赖，离线可用。
- **管理面板**：**「➕ 添加主题」**一次上传一个主题（主题名 + 金/紫品质 + 3 或 4 套时装的男女装图 + 6/7 件 + 入池时间，自动标记主题序号、自动入池最旧主题）；「➕ 添加套装」单套上传/编辑（女装图与男装图**分开上传**，可选所属主题）。
- **编辑模式**：点击页面任意文字可直接修改；一键切换套装 金装⇄紫装、紫装 6件⇄7件；每个主题行可设置「已入池 / 入池时间」；批量编辑页面文字与价格体系。
- **数据持久化**：勾选状态、收藏、预算（按账号分开）、自定义套装/主题、文字/价格/主题修改均保存在浏览器 localStorage / IndexedDB；导出/导入 JSON 备份支持全部账号；另有「💾 导出时装基本信息」用于同步数据到 GitHub。

## 数据同步到 GitHub（重要流程）

1. 在本地浏览器里用「编辑模式」调整时装数据（价格、主题、入池时间、新主题等），修改会自动保存在浏览器本地。
2. 点「编辑模式 → 💾 导出时装基本信息」，得到 **时装基本信息.json**（只含主题与时装的基础信息：名称/品质/件数/价格/主题/入池状态/入池时间，**不含拥有情况和许愿星数据**）。
3. 把该 JSON 发给开发者（我），我据此更新 `js/data.js` 并推送 GitHub；网页更新后**自动兼容老版本已拥有的数据**（按套装名匹配），并结合新版本所有时装重新计算许愿星相关数值。
4. 仓库内自带检查工具：`node tools/sync-check.js 时装基本信息.json`，输出「差异总数: 0」即表示 data.js 与导出的基本信息完全一致。

## 如何修改（给开发者）

- **改文字**：网页里开「编辑模式」直接点文字改，或改 `js/data.js` 的 `TEXT`。
- **改价格/配件名**：网页「编辑模式 → 编辑价格体系」，或改 `js/data.js` 的 `PRICE_SCHEMES`。
- **改主题/入池**：`js/data.js` 的 `THEMES`（主题名、每主题的时装、入池时间、默认已入池）；网页编辑模式里也可直接改「已入池 / 入池时间」。
- **加套装（永久内置）**：把图片放进 `images/`（女装图命名 `<套装名>女装.png`、男装图命名 `<套装名>男装.png`），在 `js/data.js` 的 `BUILTIN_SUIT_NAMES` 对应数组里加一行名字，并加入 `THEMES` 对应主题的 `suits`；默认按紫装 6 件处理，需要单独价格的套装追加 `{ name, type, partCount, prices, image }` 对象。
- **补男装图**：只需把 `images/<套装名>男装.png` 放进 `images/` 文件夹并推送即可，网页会自动识别使用，无需改代码；缺男装图时自动显示女装图。
- **加套装（网页操作）**：点「➕ 添加主题」一次上传一个主题（3/4 套，品质一致，自动入池最旧未入池主题），或「➕ 添加套装」单套上传；保存后立即生效（存在本浏览器）；如需永久保留，用「💾 导出时装基本信息」同步。


## 说明

- 所有数据保存在浏览器本地；换设备/清缓存前请先「导出数据」备份（备份包含全部账号）。
- 内置 58 套时装，按 17 个主题分组（参考文本「时装和主题的对应关系及入池时间」）；默认最后 4 个主题（14~17）未入池，其余已入池，可在编辑模式调整。
- 主题 14~17 的入池时间已按你的数据设置：**2026-09-10 / 2026-09-25 / 2026-10-10 / 2026-10-23**，到达时间后自动入池。
- 已有浏览器旧数据（单账号版）会自动迁移到「默认账号」，不会丢失。
